Factory Inventory Management System

Architecture overview: a Vue 3 single-page app talking to a FastAPI service backed by in-memory JSON data.

System architecture

Three tiers, no database. All state is loaded from JSON files at server start.

Frontend

Vue 3 + Vite · port 3000
  • Views: Dashboard, Inventory, Orders, Demand, Spending, Reports
  • Shared components: FilterBar, detail modals, profile and language menus
  • Composables: useFilters, useI18n, useAuth
  • Locales: English, Japanese
  • Charts: custom SVG
→HTTP / JSON
axios
query params

API

FastAPI + Uvicorn · port 8001
  • server/main.py: routes, Pydantic models, filtering
  • CORS middleware for the dev frontend
  • Quarter and month filtering on order_date
  • Aggregations for dashboard, spending, reports
  • Swagger UI at /docs
→Python
imports

Data

JSON files in server/data/
  • server/mock_data.py loads files once at import
  • inventory, orders, demand_forecasts, backlog_items
  • spending, transactions, purchase_orders
  • generate_data.py regenerates sample data

Data flow

How a filter change on screen becomes new data on screen.

  1. User changes a filterTime period, warehouse, category or order status in the FilterBar updates shared refs in useFilters.
  2. View requests dataThe view calls getCurrentFilters() and passes the result to a method in client/src/api.js.
  3. API client builds the requestFilters set to "all" are dropped; the rest become query params on http://localhost:8001/api/....
  4. FastAPI filters in memoryThe route filters the lists imported from mock_data.py by warehouse, category, status and month or quarter.
  5. Response is validatedPydantic response models check the shape; summary endpoints compute totals before returning JSON.
  6. View rendersRaw data is stored in refs (allOrders, inventoryItems); derived values are computed properties that drive the tables and SVG charts.

Things to know

  • The API base URL is hard-coded to http://localhost:8001/api in client/src/api.js.
  • Backlog.vue exists but has no route in main.js; backlog data is reached through other views.
  • Data is read-only at runtime. Edits to JSON files need a server restart.
  • Inventory filters do not support month, since inventory has no time dimension.
